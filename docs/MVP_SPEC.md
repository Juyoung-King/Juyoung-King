# MVP 제품 명세 (Phase 1)

목표: **"견적 요청 → 견적 비교 → 에스크로 결제 → 출고 추적"** 한 사이클이 플랫폼 안에서 완결되는 최소 제품.

---

## 1. 사용자 역할

| 역할 | 설명 | 핵심 화면 |
|------|------|-----------|
| **현지 구매자/바이어 (Buyer)** | 중동·러시아·CIS에서 차량을 구매 | 견적 요청, 견적 비교, 결제, 배송 추적 |
| **국내 바이어 (Exporter)** | 국내에서 차량을 매입해 수출 | 견적 요청 피드, 견적 제출, 출고 관리, 정산 |
| **국내 공급업체 (Supplier)** | 매매상사/딜러 — 재고 제공 | 재고 등록, 바이어 매칭 (Phase 2에서 확장) |
| **관리자 (Admin)** | 플랫폼 운영 | 검증, 분쟁 처리, 정산 승인, 신용등급 관리 |

## 2. 핵심 플로우

### 2.1 견적 요청 (헤이딜러 역경매 모델)

1. Buyer가 견적 요청 작성: 모델/연식/주행거리/색상/예산/도착 희망 국가·항구
2. 조건에 맞는 Exporter들에게 알림 (푸시/텔레그램 봇)
3. Exporter가 견적 제출: **가격(FOB/CIF 구분) + 실차 사진 + 차대번호 + 출고가능일**
4. Buyer가 견적 목록 비교: 가격순 / 평점순 / 출고일순 정렬, Exporter 프로필(이행률·거래수·리뷰) 확인
5. 견적 선택 → 거래 생성

### 2.2 에스크로 결제 (상세: ESCROW_AND_RISK.md)

거래별 가상계좌 발급 → 입금 확인 → 상태머신 진행:

```
CREATED → PAID(에스크로 입금) → PURCHASED(매입 증빙 승인, 1차 지급)
        → SHIPPED(선적 증빙 승인, 2차 지급) → DELIVERED(인도 확인)
        → SETTLED(잔금 지급, 거래 완료) 
        └→ DISPUTED(분쟁) / CANCELLED(환불)
```

- 각 상태 전이는 **증빙 업로드 + Admin(초기엔 수동) 승인**으로만 발생
- 출고가능일 초과 시 자동 알림 → N일 초과 시 Buyer에게 무료 취소권 + Exporter 패널티

### 2.3 평점·리뷰

- 거래 완료(SETTLED) 시에만 리뷰 작성 가능 (가짜 리뷰 방지)
- 자동 산출 지표: 출고일 준수율, 평균 응답 시간, 분쟁률, 누적 거래 수
- Exporter 신용등급 (A~D) → 거래 한도·선지급 비율에 연동

## 3. 화면 목록 (MVP 최소셋)

**Buyer (현지어: 러시아어/아랍어/영어)**
- 회원가입·KYC / 견적 요청 작성 / 받은 견적 비교 / 결제(입금 안내) / 거래 진행 현황(타임라인) / 리뷰 작성

**Exporter (한국어)**
- 회원가입·KYB(사업자 인증) / 견적 요청 피드(필터·알림) / 견적 제출 / 거래 관리(증빙 업로드) / 정산 내역 / 내 신용등급

**Admin**
- 증빙 검증 큐 / 정산 승인 / 분쟁 처리 / 회원·신용등급 관리 / 거래 대시보드

## 4. 기술 스택 (제안)

| 레이어 | 선택 | 이유 |
|--------|------|------|
| 프론트 | Next.js (웹 우선) | 현지 바이어는 저사양 안드로이드 비중 높음 → 반응형 웹 + PWA로 시작, 앱은 Phase 2 |
| 백엔드 | NestJS 또는 Django | 거래 상태머신·권한 관리에 구조적 프레임워크 |
| DB | PostgreSQL | 거래·정산은 관계형 + 트랜잭션 필수 |
| 결제 | 국내 PG/에스크로 제휴사 API + 가상계좌 | 라이선스 이슈 회피 (자체 에스크로는 Phase 3) |
| 알림 | 텔레그램 봇 + FCM | 러시아·CIS는 텔레그램이 사실상 표준 채널 |
| 다국어 | i18n (ko/en/ru/ar) | 아랍어 RTL 대응 포함 |
| 인프라 | AWS (서울) + CloudFront | 현지 접속 속도 확보 |

## 5. MVP에서 하지 않는 것 (스코프 아웃)

- 자체 에스크로 라이선스 (제휴로 대체)
- 공급업체(Supplier) 셀프서비스 재고 시스템 (Exporter가 수동 소싱)
- 현지 물류 추적 실시간 연동 (수동 상태 업데이트로 대체)
- 모바일 네이티브 앱
- 자동 시세/가격 추천

## 6. 성공 지표 (Phase 1 종료 기준)

- 월 성사 거래 30건 이상
- 견적 요청 → 견적 수신율 80% 이상 (요청당 평균 3개 이상 견적)
- 에스크로 거래 분쟁률 5% 미만
- 재거래율(구매자 기준) 30% 이상 — **이게 나오면 "플랫폼 신뢰가 개인 신뢰를 대체한다"는 핵심 가설 검증 완료**
