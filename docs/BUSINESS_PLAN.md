# 중동·러시아 중고차 수출 플랫폼 사업계획서

> B2B "사람 간 신뢰" 기반의 중고차 수출 시장을 "플랫폼 신뢰" 기반으로 전환한다.
> 최종 목표: **엑싯(M&A 매각)**

---

## 1. 문제 정의 — 기존 수출 시장의 한계

한국 중고차 수출은 연간 수십만 대 규모(인천항 중심)이지만, 거래 구조는 여전히 아날로그다.

| # | 한계점 | 결과 |
|---|--------|------|
| 1 | 바이어와의 **개인 신뢰 기반** 거래 (face to face) | 신규 진입자 배제, 확장 불가 |
| 2 | 수요·공급에 따른 **큰 가격 변동성** | 예측 불가능한 마진, 분쟁 |
| 3 | 수출회사가 **최종 구매자(현지 고객)를 모름** | 시장 데이터 부재, 수요 예측 불가 |
| 4 | 국내 바이어 ↔ 현지 바이어 간 **정보 비대칭** | 차량 출고 지연, 사기 피해 빈발 |
| 5 | 초기 수출업체의 **진입장벽** | 기존 네트워크 독점 구조 고착 |
| 6 | 신뢰가 한 번 깨지면 **회복 불가** | 거래 단절, 시장 비효율 |
| 7 | 대금 결제의 불안정 (러시아: 테더 송금 등 비공식 채널) | 법적·세무 리스크, 자금 추적 불가 |

핵심 통찰: **이 시장의 병목은 차량이 아니라 "신뢰"다.** 신뢰를 개인이 아닌 플랫폼이 담보하면, 거래량은 구조적으로 증가한다.

## 2. 솔루션 — 플랫폼 신뢰 기반 거래 구조

### 2.1 연결 구조

```
국내 공급업체 (매매상사/딜러)
        │  차량 등록·재고 공유
        ▼
국내 거주 바이어 (수출 바이어)  ←― 플랫폼이 신용등급·평점 관리
        │  견적 제출 (가격 + 실차 사진 + 출고가능일)
        ▼
현지 구매자/바이어 (중동·러시아·CIS)
        │  견적 비교 → 선택 → 플랫폼 에스크로 입금
        ▼
플랫폼 정산 (출고·선적 증빙 단계별 지급)
```

### 2.2 핵심 기능

1. **역경매형 견적 요청 시스템** (헤이딜러 모델의 수출 버전)
   - 현지 바이어가 원하는 차량 조건(모델·연식·주행거리·예산)으로 견적 요청
   - 국내 바이어들이 가격 + 실차 사진 + **출고가능일**을 제시
   - 현지 구매자는 가격, 평점·리뷰, 거래이력을 보고 견적 선택
2. **에스크로 결제 (거래 안전성의 핵심)**
   - 입금은 플랫폼이 중간 보관, 단계별 조건 충족 시 분할 지급 → 상세: [ESCROW_AND_RISK.md](./ESCROW_AND_RISK.md)
3. **평점·리뷰·거래이력 시스템**
   - 바이어의 이행률(약속 출고일 준수율), 분쟁률, 거래량을 지표화
   - "좋은 바이어"가 데이터로 증명되는 구조 → 신규 진입자도 실적으로 성장 가능
4. **출고 일정 관리**
   - 바이어가 출고가능일자를 입력·확정 → 지연 시 자동 알림·패널티 → 무기한 대기 문제 해소
5. **물류 수직 통합 (2단계)**
   - 탁송업체, 포워더, 현지 운영 법인을 인수·운영하여 출고→선적→통관→현지 인도까지 플랫폼 내 원스톱 처리

## 3. 이해관계자별 가치 제안

| 대상 | 기존 | 플랫폼 도입 후 |
|------|------|----------------|
| 현지 구매자 | 아는 바이어에게 송금 후 무기한 대기, 사기 위험 | 견적 비교, 평점 확인, 에스크로로 안전 결제, 출고일 보장 |
| 국내 바이어 | 공급업체 발굴이 인맥 의존, 신규 진입 불가 | 공급업체와 즉시 연결, 실적 쌓으면 신뢰 자산화 |
| 국내 공급업체 | 수출 판로가 특정 바이어에 종속 | 다수 바이어 노출 → 빠른 차량 회전, 현금흐름 개선 |
| 플랫폼(우리) | — | 거래 수수료 + 데이터 + 물류 마진 |

## 4. 수익 모델

1. **거래 수수료 (Take rate)**: 성사 거래당 차량가액의 1~3% (초기엔 0%~저율로 사용자 확보 후 인상)
2. **에스크로/정산 수수료**: 결제 금액의 일정 비율
3. **물류 부가서비스**: 탁송·포워딩·통관 대행 마진 (수직 통합 후 핵심 수익원)
4. **바이어 구독/프리미엄**: 상위 노출, 견적 우선권, 신용보증 한도 확대
5. **데이터 사업 (장기)**: 국가별 수요·시세 데이터 → 공급업체 매입 가이드, 금융사 제휴

## 5. 시장 진입 전략

### 단계별 로드맵

| 단계 | 기간(안) | 목표 | 내용 |
|------|---------|------|------|
| **Phase 0** | ~3개월 | 검증 | 특정 국가 1곳(예: UAE 또는 키르기스스탄 경유 러시아) + 기존 바이어 10~20명으로 수동 운영(콘시어지 MVP). 플랫폼 없이 카톡/텔레그램 + 수기 에스크로로 거래 흐름 검증 |
| **Phase 1** | 3~9개월 | MVP 출시 | 견적요청·에스크로·평점 기능의 웹 플랫폼. 국내 바이어 온보딩 집중 |
| **Phase 2** | 9~18개월 | 유동성 확보 | 현지 마케팅(현지어 앱/웹), 공급업체 직접 연동, 거래량 스케일 |
| **Phase 3** | 18~36개월 | 수직 통합 | 탁송·포워더·현지 법인 인수, 풀필먼트 완성 |
| **Phase 4** | 36개월~ | 엑싯 준비 | GMV·take rate·재구매율 지표 정리, 인수자 물색 |

### 콜드스타트(닭-달걀) 해법
- **공급(국내 바이어) 먼저**: 견적 요청이 오면 응답할 바이어 풀을 먼저 확보 (초기 수수료 0%, 물류비 지원)
- 수요 측은 기존 바이어들의 현지 네트워크를 플랫폼으로 이관하는 방식으로 부트스트랩
- 현지 커뮤니티(텔레그램 채널, 현지 딜러 협회) 타깃 마케팅

## 6. 경쟁 및 차별화

- **기존 플레이어**: 개별 수출업체(오프라인), 수출 중개 카페/텔레그램 채널, 일본의 SBT·BE FORWARD류 글로벌 수출몰
- **차별점**:
  1. 일본계 수출몰은 "판매자=플랫폼" 재고 판매 모델 → 우리는 **바이어 간 매칭 + 에스크로** 모델로 재고 리스크 없이 확장
  2. 국내에는 수출 특화 에스크로·평점 인프라가 사실상 부재 → 선점 효과
  3. 러시아·CIS의 결제 페인포인트(제재, 송금 제한)를 합법적 정산 구조로 풀면 그 자체가 해자

## 7. 핵심 리스크와 대응 (요약)

상세 설계는 [ESCROW_AND_RISK.md](./ESCROW_AND_RISK.md) 참조.

| 리스크 | 대응 |
|--------|------|
| 국내 바이어 먹튀 (입금 받고 차량 미매입) | 에스크로 분할지급 + 매입 증빙 기반 정산 + 보증금/신용한도 + 이행보증보험 |
| 러시아 송금/제재 문제 | 대러 제재 준수 필수 (수출금지 품목·가액 기준 확인), 제3국(CIS) 경유 합법 정산 구조, 법률 자문 선행 |
| 초기 자본·마케팅 비용 | 콘시어지 MVP로 검증 후 투자 유치, 단계별 국가 확장 |
| 운항·통관·세무 문제 | 포워더 제휴 → 인수, 관세사·세무사 자문 상시화 |
| 보이스피싱 자금 유입 | KYC/KYB, 이상거래탐지(FDS), 전자금융/외국환 규제 검토 |

## 8. 엑싯 전략

- **목표**: 거래 데이터·바이어 네트워크·물류 인프라를 갖춘 "수출 인프라 회사"로 매각
- **잠재 인수자 유형**:
  1. 국내 중고차 플랫폼 (엔카, 케이카, 헤이딜러 등 — 수출 판로 확보 니즈)
  2. 종합 물류사 (현대글로비스 등 — 완성차 물류 확장)
  3. 글로벌 중고차 마켓플레이스 / 일본계 수출몰 (한국 소싱 확보)
  4. 사모펀드 (현금흐름 + 데이터 자산)
- **엑싯 밸류 드라이버**: GMV, take rate, 재거래율, 바이어 신용 데이터(대체 불가 자산), 현지 법인·라이선스
- **마일스톤 (예시)**: 월 GMV 100억 원 + 흑자 전환 시점부터 전략적 매각 협상 개시

## 9. 검증해야 할 가설 (Phase 0 체크리스트)

- [ ] 현지 바이어가 "아는 사람" 대신 플랫폼 견적을 실제로 선택하는가?
- [ ] 국내 바이어가 수수료를 내고도 플랫폼을 쓸 유인이 있는가?
- [ ] 에스크로 분할지급 구조가 현행 외국환거래법·전자금융거래법상 가능한가? (법률 검토 필수)
- [ ] 러시아향 대금을 합법적으로 정산할 수 있는 경로가 존재하는가?
- [ ] 거래 1건당 플랫폼이 감당해야 할 운영 코스트(검수·분쟁처리)는 얼마인가?
